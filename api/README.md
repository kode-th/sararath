# Thai Gov News APIs

Python 3.13 service (uv, `uv_build` src-layout, package `thai_gov_news`): crawls Thai government sites into Postgres and serves a FastAPI read API.

See the [root README](../README.md) for the full project.

## Layout

```txt
src/thai_gov_news/
  cli.py           command-line entrypoint
  database.py      engine + session factory (DATABASE_URL required, no default)
  models.py        SQLAlchemy: sources, articles, attachments, collector_runs
  api/             app.py (FastAPI routes), schemas.py (Pydantic response models)
  collectors/      base, http, rss, prd, thaigov
  services/        runner, scheduler, seed, normalize, dedupe, thai_date,
                   ingest, export_legacy
migrations/        alembic (env.py + versions/)
sources/           sources.yaml
tests/             pytest
typings/           pyi stubs (feedparser, yaml, scalar_fastapi)
Dockerfile         base + prod + dev stages
openapi.json       generated, committed (see "OpenAPI")
```

## Setup

```bash
uv sync
export DATABASE_URL='postgresql+psycopg://user:pass@host/db?sslmode=require'
uv run python -m alembic upgrade head
uv run python -m thai_gov_news seed            # upsert sources from sources.yaml
```

`DATABASE_URL` is required. The app can use the Neon pooled host; alembic works on either.

## CLI

Run from `api/`. Always go through `uv run python -m thai_gov_news …` — bare `uv run pytest` / `uv run alembic` can fail to spawn in some environments.

```bash
uv run python -m thai_gov_news seed
uv run python -m thai_gov_news crawl --source prd          # one source
uv run python -m thai_gov_news crawl-due                   # all due (respects intervals)
uv run python -m thai_gov_news crawl-due --source rd       # restrict
uv run python -m thai_gov_news check --max-age-hours 26    # exit 1 when stale
uv run python -m thai_gov_news serve --host 0.0.0.0 --port 8000
uv run python -m thai_gov_news export-legacy --date 2026-09-20 --out data.json
uv run python -m thai_gov_news openapi > openapi.json      # dump the OpenAPI schema
uv run python -m thai_gov_news backfill-body --source prd  # re-fetch bodies after a parser fix
uv run python -m thai_gov_news dedupe-articles --source moac --dry-run  # drop duplicate rows
uv run python -m thai_gov_news repair-links --source moac --dry-run    # fix malformed source URLs
```

Also installed as the console script `thai-gov-news`.

## Read API

FastAPI app in `api/app.py`. Endpoints: `/v1/articles`, `/v1/articles/{article_id}`, `/v1/sources`, `/v1/runs`, `/v1/health`. Interactive docs (Scalar) at `/reference`, schema at `/openapi.json`. Every response is declared with a Pydantic model in `api/schemas.py`, which is what makes the OpenAPI schema (and the web client) typed.

## Collectors and cadence

`sources/sources.yaml` defines each source and its `crawl_interval_minutes` (prd/thaigov 60, moac/rd 120). `crawl-due` crawls a source only when `now - last_success_at >= interval`, so a failure retries on the next tick. Collectors use `httpx` for fetch, `selectolax` (lexbor) for HTML, and `feedparser` for RSS.

## OpenAPI

`openapi.json` is generated by the CLI and committed. It feeds the web client's generated types; regenerate and commit it after changing routes or models:

```bash
uv run python -m thai_gov_news openapi > openapi.json
```

## Docker

`Dockerfile` has three stages: `base`, `prod` (default `CMD python -m thai_gov_news`), and `dev` (uvicorn `--reload`). Compose uses the `dev` target; Render builds the `prod` stage from the frozen lock.
